# Nexa Digital — Landing Page

Landing page desenvolvida para a **Nexa Digital**, uma agência fictícia especializada em soluções digitais.

O projeto foi desenvolvido com foco em uma apresentação moderna, profissional e responsiva, destacando os serviços, projetos, resultados e formas de contato da agência.

## Sobre o projeto

A página apresenta a Nexa Digital e seus principais serviços, criando uma experiência de navegação voltada para apresentação comercial e conversão de visitantes em potenciais clientes.

Entre as principais seções estão:

- Hero / apresentação inicial
- Serviços
- Sobre a empresa
- Portfólio
- Depoimentos
- Chamada para contato
- Formulário de contato

## Funcionalidades

- Layout moderno e responsivo
- Navegação entre diferentes seções da página
- Filtro de projetos por categoria
- Modal para reprodução de vídeo
- Formulário de contato
- Integração com WhatsApp
- Ícones utilizando Font Awesome
- Estrutura preparada para envio de formulário através de backend

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- Nodemailer
- Font Awesome
